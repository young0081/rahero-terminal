## Why

《鸣潮》星炬学院剧情中出现了"拉海洛终端",但游戏内并未给出完整、可操作的终端界面——只把它的部分能力（如"飞讯"通讯）拆散成玩家日常使用的功能。玩家社区缺少一个能**真实操作、跨平台运行**的拉海洛终端，可以把这些分散的终端能力重新整合成一个高度还原《鸣潮》科技美学的交互式终端应用。

现在做的时机已经成熟：我们已收集到大量官方动态素材（"深空联合（带文字）"启动动态图标、星炬学院及多组势力/角色动态图标、黑海岸 PNG 序列等），具备高保真还原所需的视觉资产基础。由于游戏内未明确终端界面，本项目定位为"**官方美学还原 + 合理原创设计**"：视觉语言与已知功能严格贴合游戏，未明确的界面部分由我们按《鸣潮》风格补全。其中"飞讯"在游戏内有真实可见的界面，将参考玩家实机截图进行高度还原。

本项目将**开源**。为规避版权风险、保持仓库轻量，受版权的图标 / logo / 图片等素材**不提交进仓库**，改为在开发者克隆并首次运行时，由应用自动从库街区（Kuro 官方社区）下载相关素材并本地缓存；下载完成后即可离线使用。

## What Changes

- 新建一个全新的跨平台应用项目（一套代码同时面向 Windows / Linux / Android，C 端用户）。
- **开机启动序列**：以"深空联合（带文字）"动态图标作为启动动画，配合终端自检 / 上线文案，营造"终端开机联网"的沉浸感。
- **终端主界面外壳**：自研一套符合《鸣潮》科技 HUD 美学的终端桌面，包含导航、状态栏、主题系统，以及扫描线 / 故障 / 数据流等氛围特效。
- **飞讯通讯模块**：参考玩家实机截图，复刻游戏内"飞讯"界面——联系人列表、对话会话、消息流与推送提醒。
- **势力 / 角色资料库**：优先收录已有资源清单支持的 9 个势力/组织动态图标，角色条目后续单独接入，构建一个可浏览的图鉴 / 数据库模块（简介 + 动态图标展示）。
- **素材下载与缓存**：开源仓库不含受版权素材；应用首次运行时从库街区自动下载图标 / logo / 图片并本地缓存，下载后离线可用。
- **三平台响应式适配**：桌面端鼠标 / 键盘操作 + 安卓端触控操作，横竖屏与不同屏幕尺寸自适应。
- 项目分阶段交付，每个阶段独立可运行（先骨架与启动序列，再外壳，再逐模块）。

## Capabilities

### New Capabilities
- `boot-sequence`: 开机启动动画与终端上线流程（深空联合动态图标播放、自检文案、进入主界面的过渡）。
- `terminal-shell`: 终端主界面框架（桌面布局、模块导航、顶部 / 底部状态栏、主题与配色系统、科技氛围特效）。
- `feixun-messaging`: 飞讯通讯模块（联系人、会话、消息流、未读 / 推送状态）。
- `faction-archive`: 势力与角色资料库（基于现有动态图标的可浏览图鉴与详情）。
- `asset-provisioning`: 素材下载与缓存（首次运行从库街区拉取受版权素材、本地缓存、离线复用、下载失败降级）。
- `platform-adaptation`: 跨平台与输入适配（Win/Linux/Android 响应式布局、触控与鼠标键盘双输入、资源打包）。

## Impact

- **技术栈**：选定 Flutter（Dart）。理由：一套代码原生编译至 Windows / Linux / Android 三平台，动画与自定义绘制能力一流，契合"高度还原 UI 动效"的核心诉求。详细技术论证与依赖清单见 design.md。
- **目标平台**：Windows、Linux、Android（C 端消费级应用）。
- **视觉资产**：本项目开源，受版权的图标 / logo / 图片素材**不入库**，由应用首次运行时从库街区（Kuro 官方社区）下载并本地缓存，下载后离线复用。开发期用于确认风格的 `鸣潮息屏/` 本地素材与 `refs/frames/` 参考帧仅供本机参考，不随仓库分发。已抽帧确认主色：深空联合启动动画为黑底白银线条，星炬学院为青柠绿（#b4f064）+ 蓝色点缀。
- **素材合规**：仓库本体不含受版权素材；README 标注本项目为非商用粉丝向还原作品，素材版权归《鸣潮》/库洛官方所有，由终端用户运行时按需下载。
- **预期依赖**（具体版本在 design 锁定）：视频 / 序列帧播放、自定义着色器特效、本地状态管理与持久化等。
- **代码影响**：全新代码库，无破坏性变更，不影响任何既有系统。
